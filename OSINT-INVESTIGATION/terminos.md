# Lista de Terminos y siglas con definicion 

(ASN): Un ASN (Número de Sistema Autónomo) es un código numérico único que identifica a una red o grupo de redes con una política de enrutamiento propia en Internet.Internet es una red de redes*, y los sistemas autónomos son las grandes redes que componen Internet. Más concretamente, un sistema autónomo (AS) es una red grande o grupo de redes que tiene una política de enrutamiento unificada. Cada ordenador o dispositivo que se conecta a Internet está conectado a un AS.

Seed Domain : Un seed domain (o dominio de inicio) es la dirección o conjunto de direcciones web principales que se utilizan como punto de partida para que un rastreador web (web crawler) o motor de búsqueda comience a descubrir, explorar e indexar contenido en internet. 

Registro WHOIS : 
Los registros WHOIS son una base de datos pública que permite consultar y saber quién es el propietario de un nombre de dominio o una dirección IP en internet.Pueden contener Titular del dominio, datos de contacto,fechas clave,servidores dns,registrador o empresa intermediaria por la cual se compro el dominio

rangos CIDR : 
El enrutamiento entre dominios sin clases (CIDR) es un método de asignación de direcciones IP que mejora la eficiencia del enrutamiento de datos en Internet. Cada máquina, servidor y dispositivo de usuario final que se conecta a Internet tiene asociado un número único, denominado dirección IP. Los dispositivos se encuentran y se comunican entre sí mediante estas direcciones IP. Las organizaciones utilizan el CIDR para asignar direcciones IP de manera flexible y eficiente en sus redes.Los rangos CIDR corporativos son bloques de direcciones IP privadas o públicas utilizadas por las empresas para organizar y segmentar sus redes internas, sucursales y entornos de nube (como AWS, Azure o GCP).Para las redes internas (LAN, WAN y VPCs), las empresas utilizan estrictamente los rangos de IP privadas definidos por el estándar RFC 1918.

Transparencia de Certificados : 
La Transparencia de Certificados es un marco abierto de registros públicos y criptográficos diseñado para supervisar y auditar la emisión de certificados digitales SSL/TLS
Las autoridades que emiten certificados deben enviarlos a múltiples registros públicos independientes.Cualquier persona o empresa puede consultar estos registros para buscar actividad sospechosa o auditar la infraestructura de un dominio.
