# Lista de Terminos y siglas con definicion 

(ASN): Un ASN (Número de Sistema Autónomo) es un código numérico único que identifica a una red o grupo de redes con una política de enrutamiento propia en Internet.Internet es una red de redes*, y los sistemas autónomos son las grandes redes que componen Internet. Más concretamente, un sistema autónomo (AS) es una red grande o grupo de redes que tiene una política de enrutamiento unificada. Cada ordenador o dispositivo que se conecta a Internet está conectado a un AS.

Seed Domain : Un seed domain (o dominio de inicio) es la dirección o conjunto de direcciones web principales que se utilizan como punto de partida para que un rastreador web (web crawler) o motor de búsqueda comience a descubrir, explorar e indexar contenido en internet.
